# Consignas de TechPay

Este archivo se completará junto con el desarrollo de cada funcionalidad.

Cada etapa incluirá:

- Objetivo.
- Conceptos de JavaScript.
- Selectores del HTML involucrados.
- Consigna para el alumno.
- Pruebas manuales.
- Desafíos opcionales.

La regla general es no pedir ni escribir toda la aplicación de una sola vez. El código se construirá funcionalidad por funcionalidad dentro de `app.js`.
